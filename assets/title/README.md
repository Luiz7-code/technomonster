# Arte da tela de título

## Camadas animadas

`cidade-ceu-limpo.png` é o fundo fixo atual; `nuvens-camada.png`, `monstrinho-camada.png` e `arvore-camada.png` são PNGs com transparência real. Apenas os recortes recebem transformações. A imagem original permanece como fallback caso alguma camada não carregue. Não há deformação de regiões do cenário. `cidade-sem-personagens.png` preserva a etapa anterior, com nuvens fixas.

As nuvens se deslocam lentamente em uma camada independente, com margem nas laterais e borda inferior suavizada em um Canvas auxiliar criado uma única vez. O sol e a arquitetura ficam fixos. A preferência de movimento reduzido desativa o deslocamento.
